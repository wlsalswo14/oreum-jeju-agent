# 오름(OREUM) 사용자 매뉴얼

대상: 제주빅데이터센터 분석실 방문 이용자(IT 비전문가 포함) · 센터 운영 담당자

---

## A. 이용자편 — 4단계로 끝내기

### 1단계. 질문하기
- 화면 가운데 입력창에 평소 말로 질문합니다. 예시 버튼을 눌러도 됩니다.
  - "애월읍에서 카페를 창업하려고 하는데 상권이 어떤가요?"
  - "2024 최남단 방어축제(대정읍) 지역경제 효과를 알고 싶어요"
  - "모슬포 일대 버스 정류소 이용을 진단해 주세요"
- 〈분석 계획 세우기〉를 누르면 오름의 계획 Agent가 질문을 해석합니다.
  - 계획 중에는 생각·도구 호출·결과가 한 줄씩 나타나는 **'실시간 작업 기록'**(단계별 소요 초)이 표시되며, **「오름이 한 일」**을 펼쳐 전체 작업 과정을 확인할 수 있습니다.
  - AI 키가 없거나 AI 오류가 발생하면 규칙 기반으로 자동 전환되며, 같은 도구를 정해진 순서(지역→업종/축제→데이터 검색)로 호출해 작업 기록을 똑같이 남깁니다.
- 계획이 완료되면 분석 유형·지역·업종·행사 기간·비교 지역과 함께 **'오름이 고른 데이터' 카드**(데이터 ID·이름·반출 등급·이유)를 보여 줍니다.
  - 값이 틀리면 칸을 직접 고치세요(고치면 바로 반영됩니다). "확인 필요" 표시가 있으면 해당 값을 채워 주세요.
- **범위 밖 질문 안내**: 자동 분석 3종(상권·축제·버스) 밖의 질문은 거절하지 않고 관련 센터·허브 데이터, 기간, 갱신 주기, 반출 등급, 주요 항목을 포함한 **'데이터 탐색'**으로 안내합니다. 원본 반출·개인 식별·반출 기준 우회 요청은 계획하지 않고 이유를 안내합니다.
- **모든 메뉴는 왼쪽 메뉴 한 곳**에 있습니다: 새 질문 · 분석 단계 · 진행 기록 · AI 전송 기록 · 데이터 보호 원칙 · 사용 안내 · 퇴실 정리.
  왼쪽 위 **☰** 버튼으로 메뉴를 접고 펼 수 있습니다(화면이 좁으면 처음에 접혀 있음). 「진행 기록」에는 에이전트가 한 일이 시간순으로 남습니다.

### 2단계. 데이터 준비
- **센터 CSV가 없어도 바로 분석할 수 있습니다.** 체크리스트 맨 위의 「자동 포함」 항목(제주데이터허브 실데이터 —
  카드 매출 매쉬업·유동인구·상가·축제·버스 정류소 이용 등)으로 먼저 분석하고, 센터 CSV를 넣으면 같은 화면에서 최신·세부 분석으로 바뀝니다.
- 체크리스트에는 Agent의 분석 결과에 따라 **'AI 선택'** 또는 **'AI 추천'** 표시와 **'오름이 고른 이유'**가 적혀 있습니다.
  - **AI 선택**: 질문 분석에 직접 사용되는 핵심 데이터셋입니다.
  - **AI 추천**: 자동 분석에는 안 쓰지만 직접 분석할 때 참고할 데이터입니다.
- 체크리스트의 **권장** 항목은 센터에서 받으면 더 좋아지는 데이터입니다. 각 항목에는 다음이 적혀 있습니다.
  - 데이터 이름(센터 조회 화면의 이름과 같음), **권장/자동 포함/AI 추천** 구분, 없을 때 대신 쓰는 허브 실데이터
  - **받을 기간**(센터는 한 번에 1개월씩 내려받으므로, 예: "2024.01~2024.12 → 12개 파일")
  - **조회 조건**(예: 지역 조건 없이 전체 / 업종 조건) 과 **왜 필요한지**(오름이 고른 이유)
- 센터 데이터 조회 화면에서 데이터 선택 → 기간(1개월) → 조건 → 조회 → **CSV 다운로드**를 반복합니다.
- 내려받은 CSV 파일들을 오른쪽 상자에 **한꺼번에 끌어다 놓습니다**.
  - 파일 이름을 바꿔도 괜찮습니다. 오름이 **열 이름으로 데이터 종류와 기간을 자동 인식**합니다.
  - 같은 파일을 두 번 넣어도 중복은 자동 제거됩니다. 빠진 달이 있으면 알려 줍니다.
  - 센터 반입 규정에 따라 **CSV 파일만** 받습니다.
- 자동 포함 항목은 따로 받을 필요가 없습니다. 센터에 제주데이터허브 프로젝트 키가 설정돼 있으면, 질문한 지역·기간의
  일별 유동인구를 오름이 **허브 Open API로 직접 조회**합니다(진행 기록에 'Open API 직접 호출'로 표시).

### 3단계. 분석 실행
- 〈분석 실행〉을 누르면 진행 상황이 단계별로 표시됩니다(보통 10초~1분).
  1. 데이터 불러오기 → 2. 로컬 분석 → 3. **반출 기준 검사** → 4. 차트 → 5. AI 해석·문장 → 6. 보고서 생성
- 모든 계산은 이 PC 안에서 이루어지며, 원본 데이터는 외부로 나가지 않습니다.

### 4단계. 보고서·반출
- 결과 화면 탭(5개)
  - **분석 결과**: 요약, 핵심 지표, 주요 발견(그림 포함), 한계
  - **제언·활용 문안**: 바로 실행할 제언, 사업계획서 '시장 분석'/정책 보고 요약/개선 검토 메모 문안(〈복사〉)
  - **근거 자료**: 지도(정류소 크기=이용량·동종 점포·행사장 위치)와 보고서에 들어간 모든 집계표(반출 검사 통과본)
  - **반출 검사**: 표마다 통과/처리 후 통과/차단과 처리 내역, **반출 신청서 초안**(〈복사〉)
  - **작업 과정**: AI 호출 수·도구 호출 수·반출 검사 통과·AI 비용 요약, 그리고 ① 계획(도구 기록) ② 실행(이 PC에서 계산 단계) ③ AI에 보낸 것(반출 검사 통과 표 목록 + 〈AI 전송 기록〉 버튼) ④ 후속 질문에서 쓴 도구
- 결과 아래쪽 **입력창**에 이어서 질문: "한림읍이랑 비교해 줘", "매력도 지수는 어떻게 계산해?"처럼 묻기 — 에이전트(후속 질문 Agent: 도구 4종 `compare_regions`, `rerun_analysis`, `get_table`, `explain_method`, 최대 6단계)가 도구를 골라 실행(AI 연결 시 AI가 도구를 직접 선택, 키가 없으면 키워드로 선택)하며, 사용한 도구는 '작업 과정' 탭에도 남습니다.
- 〈내려받기〉 버튼 하나에서: **PDF 보고서**, **DOCX(편집용, 한글 프로그램에서도 열림)**, **반출 패키지(ZIP: PDF·DOCX·PNG 차트)**
- 반출 신청: 센터 시스템의 반출 신청 화면에 파일을 올리고, 〈반출 신청서 초안〉의 '출처'와 '활용 사유'를 붙여 넣습니다.
  승인 후 제주데이터허브 마이페이지에서 내려받을 수 있습니다(심사 최대 5일).

### 마무리 — 퇴실 정리
- 자리를 떠나기 전 왼쪽 메뉴 맨 아래 **〈퇴실 정리〉**를 누르세요. 업로드한 CSV, 결과물, AI 전송 기록이 모두 삭제됩니다.
- 반출 신청을 먼저 마친 뒤 정리하세요.

## B. 결과를 읽는 법

| 표시 | 의미 |
|---|---|
| 비공개(<10) | 반출 기준상 10 미만이거나, 다른 값으로 거꾸로 계산될 수 있어 가린 값 |
| 처리 후 통과 | 상위 단위로 묶거나(범주처리) 일부 값을 가려서(삭제처리) 반출 기준을 맞춘 표 |
| 지수(평균=100) | 비교 대상 평균을 100으로 둔 상대값. 120이면 평균보다 20% 높음 |
| 순효과(이중차분, %p) | 행사 지역 증가율 − 비교 지역 증가율. 날씨·계절 같은 공통 요인을 덜어낸 효과 |
| 실데이터 기간 | 보고서 머리말·한계 항목에 데이터 기간 표시(예: 허브 카드 매쉬업 2020.06~2021.05) — 최신 수치는 센터 CSV로 다시 분석 |
| 가상(SYNTHETIC) | 테스트용 형식 검증 파일을 넣었을 때만 표시(실제 수치 아님). 정상 이용 시에는 나오지 않음 |

## C. 운영 담당자편

### 설치(최초 1회)
1. 폴더를 `C:\OREUM` 등에 복사 → `install.bat` 더블클릭(인터넷 필요, 3~5분)
2. 마지막에 나오는 **자가 점검** 결과가 모두 [정상]인지 확인
3. AI 사용 시 `.env` 파일(메모장)의 `OPENAI_API_KEY=` 뒤에 키 입력 후 저장 → 이용자에게 키가 노출되지 않습니다(아래 발급 절차).
4. 바탕화면에 `run.bat` 바로가기를 만들어 두면 편리합니다.

### AI(OpenAI) API 키 발급·설정(센터 담당자, 최초 1회)
오름은 **OpenAI `gpt-6-luna`(추론 강도 high)** 기준으로 검증되었습니다. 키만 넣으면 같은 설정으로 동작합니다.
1. https://platform.openai.com 접속 → 기관 이메일로 가입·로그인
2. **Settings → Billing**에서 결제 수단 등록(선불 크레딧 충전)
3. **Settings → API keys → Create new secret key** → 이름(예: `jeju-bigdata-center-oreum`) 입력 → 생성된 `sk-...` 키 복사
   (키는 생성 직후 한 번만 보이므로 안전한 곳에 보관)
4. 오름 폴더의 `.env` 파일을 메모장으로 열어 `OPENAI_API_KEY=` 뒤에 붙여 넣고 저장
   (`OREUM_LLM_PROVIDER=openai`, `OREUM_LLM_MODEL=gpt-6-luna`, `OREUM_LLM_EFFORT_*=high`는 기본값 그대로)
5. 확인: **`check_ai.bat` 더블클릭** → `[정상]`이면 완료(오름과 같은 형식의 요청을 1번 보내 확인, 비용 1원 미만). 자세한 요청 형식·문제 해결은 `docs/AI_API_설정_안내.md`.
   분석을 한 번 실행한 뒤 왼쪽 메뉴의 〈AI 전송 기록〉에 호출 기록이 보이면 실제 연결까지 확인된 것입니다.
6. (권장) **Settings → Limits**에서 월 사용 한도(예: 1만 원)를 설정해 비용 상한을 둡니다.
- 키는 이용자 화면·보고서·로그 어디에도 표시되지 않습니다. 교체 시 `.env`만 바꾸면 됩니다.
- 센터 방화벽 허용 주소: `api.openai.com`(HTTPS 443)
- (선택) Claude를 쓰려면 `.env`에서 `OREUM_LLM_PROVIDER=anthropic`, `OREUM_LLM_MODEL=claude-opus-5-5`, `ANTHROPIC_API_KEY=...`
  (https://console.anthropic.com → API Keys), 허용 주소 `api.anthropic.com`.

### 제주데이터허브 프로젝트 키 발급·설정(선택, 최초 1회)
키가 없어도 오름에 들어 있는 허브 실데이터·스냅샷으로 동작합니다. 키를 넣으면 질문한 지역·기간의 일별 유동인구를 오름이 직접 조회합니다.
1. https://jejudatahub.net 회원가입·로그인 → **마이페이지 → 프로젝트 관리 → 프로젝트 만들기**
2. 데이터 페이지에서 아래 3개를 열어 각각 **〈프로젝트 담기〉** → 만든 프로젝트 선택 → 확인
   - `읍면동 단위 내국인 유동인구`(jejudatahub.net/data/view/data/583)
   - `버스 정류소 기본 정보`(…/612), `일일 정류소별 버스 이용자 정보`(…/613)
3. **마이페이지 → 프로젝트 관리 → 프로젝트 이름** 클릭 → **프로젝트키** 복사
4. `.env`의 `JEJU_HUB_PROJECT_KEY=` 뒤에 붙여 넣고 저장 → `run.bat` 재실행
- 데이터별 하루 1,000회 호출 한도(한국시간 오전 9시 초기화). 오름은 디스크 캐시와 여유분 보호로 한도를 넘지 않게 호출합니다.
- 허용 주소: `open.jejudatahub.net`(HTTPS 443)

### 매일 운영
- 시작: `run.bat` 실행(검은 창은 열어 둔 채로 사용) → 브라우저 자동 열림
- 종료: 검은 창 닫기
- 일괄 정리: `cleanup_all.bat` — 모든 이용자 작업 공간 삭제(반출 승인 보존 폴더 `approved_outputs`는 유지)

### 비용 관리
- 기본 모델은 OpenAI `gpt-6-luna`(입력 100만 토큰당 0.10달러, 출력 0.50달러)로, 보고서 1건당 수 원~수십 원 수준입니다
  (입출력 토큰에 따라 다름). 왼쪽 메뉴의 〈AI 전송 기록〉에서 호출 횟수·토큰·추정 비용을 확인할 수 있습니다.
- 더 높은 품질이 필요하면 `OREUM_LLM_MODEL=gpt-6.1-terra`(약 10배 비용)로 바꿀 수 있습니다.
- AI를 완전히 끄려면 `OREUM_LLM_ENABLED=0` — 규칙 기반 문장으로 보고서가 계속 생성됩니다.

### 보존이 필요한 경우
- 반출 승인을 받은 결과물을 다음 분석에 쓰려면 `approved_outputs` 폴더에 보관합니다(삭제 대상 제외).
  센터 정책상 보존 대상·필요성·활용 방식은 본 매뉴얼에 명시된 이 폴더로 한정합니다.

## D. 문제 해결

| 증상 | 원인·해결 |
|---|---|
| install.bat에서 uv 설치 실패 | 보안정책으로 PowerShell 설치가 막힌 경우 → Python 3.12를 python.org에서 설치 후 다시 실행(자동으로 PC의 Python 사용) |
| 패키지 설치 실패 | 인터넷/프록시 확인. `pypi.org`, `files.pythonhosted.org` 허용 필요 |
| 브라우저가 자동으로 안 열림 | 주소창에 `http://127.0.0.1:8765` 입력 |
| "포트 사용 중" 오류 | 이미 실행 중인 창을 닫거나 `.env`의 `OREUM_PORT`를 다른 번호(예: 8766)로 변경 |
| 〈AI 전송 기록〉에 호출이 없거나 오류 표시 | `.env`의 API 키 확인 후 `check_ai.bat` 실행. 키가 없어도 규칙 기반으로 동작 |
| AI 호출 실패(네트워크) | 센터 보안정책(DLP)·방화벽에서 `api.openai.com` 허용 필요. 실패 시 자동으로 규칙 기반 전환 |
| 파일을 "인식하지 못함" | 센터에서 내려받은 원본 CSV인지 확인(엑셀로 저장 변환한 파일은 열 이름이 바뀔 수 있음) |
| "빠진 기간" 경고 | 체크리스트 기간 중 빠진 달의 CSV를 추가로 내려받아 넣기 |
| PDF가 안 만들어짐 | Edge/Chrome이 없거나 실행이 막힌 경우 → DOCX·HTML 보고서는 정상 생성. HTML을 열어 인쇄→PDF 저장 |
| 차트 글자가 깨짐 | Windows 기본 글꼴 '맑은 고딕' 필요 |
| 지도 배경이 안 보임 | 외부 지도 타일 차단 시 점만 표시됨(보고서에는 정적 지도 포함) |
| 화면이 느림(저사양 PC) | Windows 설정 → 접근성 → 시각 효과 → **애니메이션 효과 끄기** → 배경 영상(바다·억새)이 멈추고 정지 사진으로 바뀜 |
